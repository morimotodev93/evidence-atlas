# Information and Research Policy

Follow this policy when researching or verifying external information.

## Source Priorities

- Use credible sources supported by objective evidence.
- For technical information, prefer primary sources whenever possible, such as official documentation, official specifications, standards bodies, and official repositories.
- Do not rely solely on search results or secondary sources. Check the original source whenever possible.
- Verify important facts against multiple independent sources when needed.

## Currency and Version Relevance

- Prefer up-to-date information when addressing current specifications or conditions.
- Check publication dates, update dates, and applicable versions.
- Do not present outdated information as the current specification.
- Use web search when needed to verify answers that depend on current specifications or recent information.
- When behavior differs by version, clearly identify which version the information applies to.

## Facts and Inferences

- Clearly distinguish verified facts from assumptions, inferences, and common practices.
- State when the available information is insufficient.
- Do not present unsupported claims as verified facts.
- For disputed topics, fairly represent the main differing views.

## Source Attribution

- Where possible, identify the main sources used, including their names, publishers, and publication or update dates.
- For technical specifications, also identify the applicable versions where possible.
- If project specifications conflict with external information, explain the differences rather than silently overriding either one.
